# Credits and Acknowledgements

Zeus Hermes Orchestrator is an independent open-source project created and
maintained by [BrainX](https://github.com/brainx).

## Hermes Agent and Nous Research

Zeus is built to orchestrate
[Hermes Agent](https://hermes-agent.nousresearch.com/), the open-source agent
developed by [Nous Research](https://nousresearch.com/). Hermes provides the
agent runtime, profile model, gateway, and tool ecosystem that Zeus supervises.
We gratefully acknowledge the Nous Research team and the Hermes Agent
contributors for making that foundation available to the open-source
community.

Official upstream resources:

- [Hermes Agent documentation](https://hermes-agent.nousresearch.com/docs/)
- [Hermes Agent source repository](https://github.com/NousResearch/hermes-agent)
- [Nous Research](https://nousresearch.com/)
- [Nous Research on GitHub](https://github.com/NousResearch)

Zeus and Hermes Agent are separate projects. This repository contains the Zeus
orchestration layer; Hermes Agent remains governed by its upstream project,
license, and maintainers. No sponsorship or endorsement by Nous Research is
implied.
